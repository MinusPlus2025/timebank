# 设计原则：不同年龄、不同文化都能用

> 用户要求（2026-10-10）：UI/UX 要方便不同年龄、不同文化背景的人使用，并有很好的视觉和交互体验。
> 这是硬性要求，评审时对应“产品质量与完成度”。

## 1. 任何年龄都能用
- **一屏只做一件事**：每个页面只有一个主按钮，按钮大（高度 ≥ 56px）、字大（正文 ≥ 18px，可切换“大字模式”）
- **不出现加密术语**：界面上没有“钱包、Gas、交易哈希、签名”，只有“刷脸”“盖印”“送给家人”。技术细节收在“查看链上记录”里
- **刷脸代替密码**：注册和每次确认都只需要刷脸或指纹
- **图标 + 文字 + 声音**：关键操作同时有图标、文字和音效（盖印的“咚”一声），不识字或视力不好的人也能明白
- **出错能恢复**：每一步都可以返回；错误提示说明“发生了什么、下一步怎么做”，不用技术语言
- **家人代办**：老人可以由家属或社区工作人员协助注册

## 2. 任何文化都能用
- **多语言**：首版中文 + 英文，文案全部抽成语言包，方便以后加日语、韩语、西班牙语等；布局预留从右到左（阿拉伯语、希伯来语）的支持
- **印章随文化变化**：中文环境用方形篆刻印，英文环境用圆形火漆封印；同一个链上种子生成，含义相同
- **颜色**：朱红只用在“印章”上（东方代表信用，西方火漆也是红色）；错误提示不用大面积红色，用图标加文字说明
- **伦理一致**：不显示“谁欠谁”、不做排行榜、可以匿名；用“谢谢你”而不是“记账”
- **日期、数字本地化**：按用户语言显示时间格式和数字格式

## 3. 视觉与交互
- **风格**：宣纸白底、墨色文字、朱砂印章；温暖、安静、留白多
- **盖印动画**：两个人确认后，印章从上方“落下”并轻微晕染，配一声清脆音效、手机轻微震动
- **光阴印谱**：收到的印章像一本册子一样排列，可以翻看
- **尊重系统设置**：支持深色模式；系统设置“减少动态效果”时关闭动画
- **无障碍**：对比度达到 WCAG AA；所有按钮有读屏标签；可以只用键盘操作

## 4. 页面清单（MVP）
1. 欢迎 / 刷脸注册
2. 我的时间（余额、我的印谱）
3. 盖印（发起“谢谢你” → 对方扫码 → 双方刷脸 → 落印）
4. 送给家人
5. 开门验真
6. 链上记录（给评委和好奇的用户看）

## 5. 视觉改版（2026-10-10，用户反馈：第一版太 AI、太模板化）
第一版的问题：居中卡片、大圆角、emoji 图标、黑色胶囊按钮、系统字体，看起来是通用模板。
给出三个差异很大的方向供用户选择（样图见 `assets/mockups/`）：
- **A · 印谱册页**：像一本博物馆图录。竖排标题、宋体/衬线、细线分隔、大写数字“贰小时”、无卡片、无 emoji
- **B · 红绳结**：每一小时是红绳上的一个结。手写感字体（霞鹜文楷），“按住盖印”的圆形大按钮代替普通按钮
- **C · 时间票**：每一小时是一张带撕线的票（致敬早期时间银行用的纸质票据）。深绿底、等宽编号、撕下一张送家人

## 6. 场景动效引导（用户要求：作为 App 要有场景动效引导）
- 首次打开：3 屏场景引导，用动画讲清“帮忙 → 双方盖印 → 时间可以送给家人”，可跳过
- 关键操作都有“演示动画”：第一次盖印时，先用动画示范两个人怎么操作
- 每个方向的专属动效：
  - A：翻页进入；印章落下后墨色晕开；印谱像翻册页
  - B：红绳从左到右画出来；盖印时打一个新结；按住时外圈像墨一样填满
  - C：新票从“打印机”里吐出来；送家人时撕下票根；盖印时“咚”地落章
- 尊重系统“减少动态效果”设置：开启时只保留淡入淡出
